Select tables in step 2, then generate mapping suggestions.

Suggestions come from fixed rules (names, abbreviations, data types, lengths and keys). They are not applied until you approve the mapping, and the score is a rule of thumb, not a probability. Nothing is migrated automatically.

Validate and approve the mapping

The server checks that every table and column exists, that no target column is used twice, that required target columns are mapped and that data types fit. Approval is a separate, explicit step.

Migration preview

The preview re-checks the approval and the current structure of both databases, counts the source rows and shows what a migration would do. It writes nothing to either database.
